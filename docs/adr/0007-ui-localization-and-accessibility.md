# ADR 0007: UI information architecture, localization, and accessibility

- Status: Accepted
- Date: 2026-09-02
- Authority: Master Plan section 15

## Decision

The UI exposes General, Advanced, and Expert disclosure levels and is designed from its first component for Traditional Chinese, Simplified Chinese, English, Japanese, and Korean. Traditional Chinese is the product-authoring reference and English is the protocol/documentation reference.

## Consequences

Stable English message keys, explicit fallback, terminology review, keyboard-complete operation, screen-reader labels, color-independent state, reduced motion, text scaling, and a Pet-independent approval route are release requirements rather than later polish.
